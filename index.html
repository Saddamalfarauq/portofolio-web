Tugas Akhir / Skripsi Full-Stack AI + GIS

WebGIS Flood Detection System

JavaScript Python CNN Mask R-CNN WebGIS GeoJSON

Sistem kecerdasan buatan terpadu untuk mendeteksi dan memetakan potensi risiko banjir di Kabupaten Maros. Menggunakan Convolutional Neural Network (CNN) untuk klasifikasi awal dan Mask R-CNN untuk segmentasi area tergenang secara presisi dari citra satelit, yang divisualisasikan secara langsung melalui platform peta interaktif WebGIS.

  • ✓ Segmentasi pixel-level otomatis pada citra satelit
  • ✓ Visualisasi poligon banjir interaktif di atas layer peta wilayah
  • ✓ Antarmuka responsif ramah pengguna untuk monitoring potensi bencana
